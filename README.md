Career AI Copilot – Project Overview

Career AI Copilot is a full-stack AI-based application that helps users analyze their resume against a job description and prepare for interviews.

Technologies: React.js, Node.js, Express.js, MongoDB, JWT, Google Gemini AI, JavaScript, HTML/CSS.

How it works:

User uploads/pastes their resume and job description.
AI analyzes the resume and identifies skill gaps and matching skills.
It generates interview questions, behavioral questions, and a preparation roadmap.
JWT authentication is used for secure user login and protected APIs.
Frontend communicates with the backend through REST APIs.
